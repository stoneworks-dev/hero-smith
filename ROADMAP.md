# Roadmap

This document outlines **planned ideas and potential future improvements** for the project.

**Important note**  
This roadmap is **not a promise**. Items listed here are ideas, experiments, or wishes.  
Some may never be implemented due to technical limitations, licensing constraints, or time availability.

Development is currently **slow and best-effort**, as this is a solo project with limited time from an inexperienced developer.

---

## Ongoing Focus
- Bug fixing based on user feedback and internal testing

---

## Planned Updates

- Make abilities more dynamic (reacting to changes in hero stats)
- Allow users to create **homebrew variants** of all elements:
  - Classes
  - Subclasses
  - Ancestries
  - Abilities
  - And more
- Add hero image support
- In-app dice rolling
- Import / export Codex heroes
- Creature stat blocks for:
  - Retainers
  - Summons
  - Elemental forms
- Retainer support
- Add new official content **once MCDM allows free use under their Creator License**
- New User Guide at first run of the app
- Better Icons when I can get some
- Add Director resources:
  - Initiative tracker
  - Homebrew monster stat calculator
  - Encounter value
  - Random generated encounter rewards
  - And more
- Cheat sheet for both players and directors
- Export to PDF. If I can use the official sheets it would be perfect!
---

This roadmap will be updated over time as ideas evolve or are discarded.
