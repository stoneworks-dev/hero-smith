# Known Issues

This document lists **known limitations, bugs, and uncertainties** in the current state of the app.

The list is **not exhaustive** and will grow as new issues are discovered.

---

## Current Known Issues

- Duplication detection system errors  
  - False positives  
  - Missed duplications

- Hero stat application issues  
  - Not all stats may be properly updated or applied in every case. Further testing required.

- Hero features may be incomplete  
  - Some features, skills, languages, abilities, or effects may be missing or not fully applied. Further testing required.

- Missing components  
  - Some app elements may have been unintentionally left out. Further testing required

---

## Reporting Issues

If you discover an error or bug — **even if it is already listed here** —  
please report it so it can be reviewed and verified.

This document will be updated as more issues are identified.

---

## Note on Progress

As with the roadmap:
- Development time is limited
- Fixes may take time
- Some issues may remain unresolved for long periods

Your patience and feedback are appreciated.
